ERGONOMICS EXPLORATION

The central architectural question for The Klang Suite's UI evolution: Is the uniform 2x5 / 2x4 card grid optimal, or does it create visual monotony and obscure the signal path? Below is an exploration of 4 alternative layout paradigms, analyzing how they balance musician intuition, desktop screen space, and 1:1 hardware parity with the dadamachines TBD-16.

💡 The Recommended Golden Path: The "Grouped Pod Pipeline" (Hybrid 1 + 2)

How do we solve the "wall of sliders" without breaking our 4-control JSON schemas and TBD-16 hardware mapping? We adopt the Grouped Pod Pipeline:

Pod 1: Oscillator Core

Carrier and Modulator cards sit on a deep cyan underlay plate with an integrated mini-harmonic scope header. Instantly flags sound generation.

Pod 2: Timbre & Modulation

Pitch Envelope, Filter, and Filter Envelope sit on a deep violet plate with animated envelope curve badges.

Pod 3: Summing & Dynamics

Mixer, Transient Shaper, and Limiter on an amber plate. Signals travel with subtle chevron arrows (→) between pods.

This preserves 100% of our existing C++ cards and APVTS bindings, keeps the TBD-16 4-encoder parity intact, but transforms the visual experience from a "sterile spreadsheet grid" into a tactile, flowing synth console!

🎨 Visual Languages Beyond Cards: Main Synth Pages vs. Modular FX/Mod

The Core Principle: Visual form follows functional reality. The sound engine is fixed; FX and modulations are reconfigurable.

PARADIGM SPLIT
🎛️ Main Synthesis Pages (Voice 1, Voice 2, Transients, Output)

Functional Reality: The signal path is fixed and directional. An oscillator feeds a filter, which feeds an amplifier. It is NOT drag-and-drop.

Why Cards Fail Here: Forcing fixed signal paths into isolated, floating rectangular cards makes the instrument feel like an unsorted box of spare parts rather than an acoustic engine.

→ Solution: Unified Sculpted Console / Milled Instrument Chassis
🧩 FX Rack & Modulation Dock (Pre/Post FX, Mod Matrix, Strip)

Functional Reality: The signal path is dynamic, reconfigurable, and arbitrary. Slots can be reordered; mod sources are patched via cables.

Why Cards Excel Here: Cards, tiles, and pedal boxes are the ideal physical metaphor because musicians intuitively understand dragging, swapping, and patching separate units.

→ Solution: Keep Modular Drag-and-Drop Eurorack Cards & Tiles!

⚙️ JUCE Architecture & C++ Implementation

How do we implement this without breaking our data schemas or TBD-16 hardware mapping?

  • Main Synth Pages: MainSynthesisChassisComponent draws a single contiguous slate faceplate with milled groove lines and vector bus paths via paint(). Sliders sit directly on the chassis without individual card wrappers.
  • Effects & Mod Pages: Continue using ModuleCardComponent with juce::DragAndDropContainer, providing reorderable slots and drop targets.
  • TBD-16 Hardware Parity: 100% preserved! The embedded OLED firmware still addresses blocks in 4-parameter pages. Only the desktop rendering surface evolves from "floating cards" to an "integrated instrument console."

💡 The Universal Hybrid Axiom: "Hardware has Encoders; Desktop has Pixels."

No successful hybrid instrument restricts its desktop plugin to the 4/8-knob enclosure limits of its microcontroller. Desktop UIs must optimize for visual adjacency across coupled circuits (e.g. Cutoff directly next to Envelope Depth). The embedded hardware firmware consumes the exact same data model, but paginates the 6–8 controls into deterministic Bank A (Knobs 1–4) and Bank B (Knobs 5–8) toggled with a single encoder push.

1. Unified FM Core

Carrier 1 and Modulator 1 combined into a cohesive double-width cockpit. Adjusting FM ratio, depth, and pitch envelope requires zero jumping across card borders.

2. Unified Filter & Dynamics

Filter Core (Type, Slope, Cutoff, Res) sits in Col 1; Filter Dynamics (Env Depth, Decay, Slope, Drive) sits in Col 2. Instant visual coupling of resonant sweeps.

3. Reclaim 37.5% Dead Space

Eliminates the 3 dead metal blanking plates on Transients and Amp pages! Adds dedicated Noise Generators, Multi-Burst Claps, and Console Saturation.

VISUAL ENGINEERING

De-boxes modules using optical relief pairs: 1px deep shadow (#05070a) above a 1px specular catch-light (0x18ffffff). Knobs sit in a recessed bay (#161b22) 1mm into the plate with countersunk rotary wells.

PCB microstrip traces route Left-to-Right: Carrier → Mod FM → Filter → Output. Rest state is ghosted copper; audio triggers ignite a 3-pass multi-bloom glow (Cyan Audio / Amber Modulation) with travelling photon pulses.

Background metal is cached to an offscreen juce::Image (blitted in O(1) time at 0.3% CPU). Traces route strictly through 18px clear gutters, repainting only traceBounds.expanded(4) — skipping all 20+ knobs!

3. TBD-16 Hardware Pagination Algorithm

Deterministic Chunking: The hardware firmware parser chunks every group's parameter array into quads of 4:

  • Chunk 0 (Params 0-3) → Page V1_FMCORE_A (Encoders 1..4)
  • Chunk 1 (Params 4-7) → Page V1_FMCORE_B (Encoders 1..4)
  • rhythm_strip → Encoders bind to Bank A (Levels), push toggles to Bank B (Decays)
Zero Code Duplication: The exact same JSON file dictates the rich 8-control desktop layout AND the 4-knob hardware pages!

4. Reflection & Safety Gauntlet

  • 100% Parameter Reflection: gui_tests.cpp asserts all registered APVTS parameters exist in the JSON groups.

  • Zero Heap Allocations: SystemStats::getNumAllocations() asserts 0 allocations over 30 timer iterations.

2. Visual Modulation Tracer Splines Bitwig / 0-Coast Style

Glowing dynamic Bézier tracer cables interconnect bottom dock tiles to arbitrary target sliders across the faceplate.

  • Full-Window Transparent Overlay: Sized to the full plugin bounds, placed at the highest Z-order. Calls setInterceptsMouseClicks(false, false) to never impede underlying controls.
  • Strict Dirty-Rect Gutter Routing: Never calls full repaint(). Calculates bounding union of old vs new spline frames: repaint(oldBounds.getUnion(newBounds).expanded(padding)).
  • Zero-Allocation Multi-Bloom: Avoids expensive drop-shadow filters. Strokes the pre-allocated cubic Bézier path 3 times: wide 20% alpha outer aura, medium 50% glow, and crisp 1px solid core.
