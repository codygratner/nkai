# Antigravity Sidecar Framework
A permanent, standalone framework and template repository for the Sidecar Workshop & Research Board.

## Architecture
The Asymmetric Sidecar Split: terse chat, rich sidecar.
- **Standalone Artifact**: Use dist/standalone-template.html for single-file, zero-dependency offline rendering.
- **UI Extension Plugin**: Use the plugin/ directory to load as an Antigravity UI Extension.

## Declarative Configuration & Data Contracts
The UI is driven by standard schemas located in core/schema.json.
